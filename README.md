# devbox 1.0 Alpha

**devbox** - это программа, которая автомачитески создаёт все необходимые папки для начала вашего программирования.

---

## 💻 Что создаёт devbox

- `C:\Dev\Projects` - для ваших проектов
- `C:\Dev\Archiv` - архив проектов
- `C:\Dev\Experiments` - для экспериментов
- `C:\Data\Media` - для изображений, видео и музыки
- `C:\Data\Downloads` - для загруженных файлов
- `C:\Data\Docs` - для документов

---

## 📢 Преимущества

- Быстрое создание структуры папок
- Подходит для навичков
- Работает на **Windows**

---

## Как установить

на Github есть готовое приложения.
1. Скачайте репозиторий или exe-файл
2. Запустите `devbox.exe` или `python src/main.py`
3. Все папки будут созданы автоматически.
